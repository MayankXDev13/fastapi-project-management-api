## 2. Architecture

```
main.py (FastAPI + lifespan + AuthMiddleware + 5 routers)
├── middleware/auth_middleware.py — BaseHTTPMiddleware, PUBLIC_PATHS = /auth/register, /auth/login, /auth/refresh, /auth/verify-email, /auth/forgot-password, /auth/reset-password, /docs, /openapi.json, /redoc — else requires Authorization: Bearer <jwt> → decode_token → request.state.user
├── deps.py — get_current_user (from request.state.user)
├── database.py — engine = create_engine(DATABASE_URL, check_same_thread=False), get_session(), create_tables()
├── config.py / utils/auth.py — hash_password/verify_password (bcrypt), create_access_token/decode_token (PyJWT), generate_raw_token (token_hex 32), hash_token (sha256)
├── models.py — 6 tables + 4 enums
├── routes/ → schemas/ → services/ (thin → validated → business logic)
└── tests/ + pytest.ini + README.md (added this session)
```

**Tables (`models.py`):**
- `users` — id(uuid), email(unique), hash_password, is_email_verified
- `verification_tokens` — id, user_id(FK), token_hash(sha256), type(email_verification|password_reset|refresh_token), expires_at, used_at
- `projects` — id, name, description, owner_id(FK), status(active|archived|completed)
- `project_members` — id, project_id(FK), user_id(FK), role(owner|admin|member|viewer), UNIQUE(project_id,user_id), owner auto-added in `project_service.create_project`
- `project_tasks` — id, project_id(FK), title, description, assigned_to(FK), created_by(FK), due_date, status(todo|in_progress|review|completed)
- `project_task_comments` — id, task_id(FK), user_id(FK), comment

**Auth flow:** register → VerificationToken(email_verification 24h) → verify_email, login → bcrypt → access JWT + VerificationToken(refresh 7d), refresh → validate hash+type+unused+not_expired → mark used_at → rotate, logout → mark used_at, forgot → always 200 → VerificationToken(password_reset 1h), reset → validate → hash_password(new).

**API prefixes:** `/auth` (register/login/refresh/logout/verify-email/forgot/reset, GET/PUT /auth/me, PUT /auth/change-password), `/projects` (CRUD, GET ?page&page_size&search scoped to ProjectMember, ilike name/description), `/projects/{project_id}/tasks` (CRUD, CreateTaskRequest **requires** project_id in body + path), `/projects/{project_id}/tasks/{task_id}/comments` (CRUD, CreateCommentRequest requires task_id), `/projects/{project_id}/members` (GET, POST user_id+role, PUT new_role, DELETE)

**Note:** `/auth/logout` is NOT public — requires Bearer auth (caused failures).
